ServiceNow change PDF downloader

Downloads the PDFs attached to a change, or the change record itself as a PDF, using the ServiceNow login already open in your browser.

Set it up once

  1. Show your bookmarks bar (Ctrl+Shift+B).
  2. Drag this button onto the bar: Get CHG PDFs

If dragging is blocked, right-click the bar → Add page, name it "Get CHG PDFs", and paste the code below (with javascript: in front) as the URL.

Use it

  1. Open any ServiceNow page and make sure you're logged in.
  2. Click Get CHG PDFs in the bookmarks bar.
  3. Enter one or more change numbers, then choose what to download.
  4. If the browser asks to allow multiple downloads, allow it.

Bookmarklets blocked? Use the console

On a ServiceNow tab press F12, open Console, paste this and press Enter.
