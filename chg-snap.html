CHG Snap

One click on a ServiceNow change saves it as a PDF, reads the compliance checklist from the same folder, and builds a Copilot prompt that checks the PDF against it.

Set it up once

  1. Replace your old CHG Snap bookmark: drag this onto the bookmarks bar: CHG Snap
  2. Click it on a ServiceNow tab. The panel's settings rows sit under the change number box:
    • Save folder: pick a folder inside your OneDrive (e.g. "CHG Reviews"). Choose "Allow on every visit" if offered.
    • OneDrive link: open that same folder in OneDrive on the web and paste the address-bar URL. This lets the prompt link straight to each PDF.
    • Agent link: open your CHG Reviewer agent in Copilot and paste its address-bar URL (…/chat/agent/…).
  3. Put your compliance checklist in the save folder. A name containing "checklist", "compliance" or "control" is picked first (e.g. CHG Compliance Checklist.docx). CHG Snap only uses its file name: the checklist is never pasted into the prompt or opened. The prompt tells Copilot to use that file from your OneDrive (with a direct link when the OneDrive link setting is filled in).

Use it

  1. On an open change: click CHG Snap. It saves the PDF straight away.
  2. Several changes: type or paste them into the box (commas, spaces or one per line, e.g. a column copied from Excel) and press Enter. Numbers without "CHG" get it added. Highlighting CHG numbers on a ServiceNow list before clicking also works.
  3. Edge Copilot (quickest): click Ask Edge Copilot. The PDF(s) open in new tabs and one prompt, including the full checklist, is copied. Press Ctrl+Shift+. (or the Copilot button in the toolbar), paste and send. Copilot reads the open PDF.
  4. Change the prompt: click Edit next to Prompt in the panel, change the text, and click Save. It's remembered for next time; Reset to default brings back the original.
  5. Or your CHG Reviewer agent: click Open in CHG Reviewer, paste, attach the PDF with +, send.

Give OneDrive a few seconds to sync before sending, or Copilot may not find the file yet.

Button not working? Use the console

On a ServiceNow tab press F12, open Console, paste this and press Enter.
