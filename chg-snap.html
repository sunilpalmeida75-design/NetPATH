CHG Snap

One click on a ServiceNow change saves it as a PDF and hands it to your CHG Reviewer agent.

Set it up once

  1. Delete the old "Get CHG PDFs" bookmark.
  2. Drag this button onto your bookmarks bar: CHG Snap
  3. First click: pick a save folder inside your OneDrive. If the browser offers "Allow on every visit", choose it.
  4. In the panel that appears, click Set agent link and paste your agent's Share / Copy link.

Use it

  1. On an open change: click CHG Snap. That's it, no questions.
  2. Several changes: highlight the CHG numbers on any page (a list works), then click.
  3. Anywhere else: click, and type the change number(s).
  4. Click Open CHG Reviewer agent in the panel, paste (Ctrl+V), attach the PDF, send.

Files are saved as CHG0012345.pdf. Folder saving needs Edge or Chrome; otherwise files go to Downloads.

Bookmarklets blocked? Use the console

On a ServiceNow tab press F12, open Console, paste this and press Enter.
